How it works

  1. Drop in a MIDI file (search "song name midi"). The commands appear straight away: melody, bass and drums/harmony are all picked automatically.
  2. Optional: change the part of the song, the instruments, or which track a layer uses. Everything updates instantly.
  3. Click ▶ Minecraft preview to hear what the note blocks will sound like.
  4. Build it with Copy next: each click copies the next command and tells you the repeater delay to set.

Everything runs on your PC. Nothing is uploaded anywhere.
